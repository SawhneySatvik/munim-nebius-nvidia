# ADR-008 · Simulated suppliers over A2A in one service

**Status:** accepted 9 Oct 2026. **Amended 11 Oct 2026 by ADR-014 (ledger R45 F4; ADR-014 §10, §14 P3).**

**Ledger:** R7, R22, R23, R35, R45.

**Context.** Negotiation should be a real network call, and the deploy count matters.

> **Superseded (11 Oct 2026, R45/ADR-014)**: the original decision and consequences:
>
> **Decision.** `suppliers-sim` hosts three A2A agents (own path, own agent card with the public URL, own pricing personality). intel uses `RemoteA2aAgent` with an httpx client carrying a Cloud Run ID token. RFQs are non-binding; the result is a PO draft.
>
> **Consequences.** Labelled simulated everywhere. A2A pieces are Experimental in ADK — wrap them behind our own tool so a fallback in-process call is possible.

**Why it changed:**
- **The ADK wrappers were the wrong layer.** `RemoteA2aAgent` and `to_a2a` make a supplier an ADK *agent*, so every round runs an LLM agent loop on our side. They are also Experimental in ADK (R5).
- **The pack already defines the negotiation shape** (pack §6): the counter is the best rival, with ≤ 2 rounds.
- **The founder decided F4 (hybrid).** The AI picks the move, the rules bound it, the deal review is deterministic, and the PO is a draft.
- **The ADK extra pulls in more than it names.** Installing `google-adk[a2a]` pulls `a2a-sdk[http-server]` (review m3), so the lockfile `litellm` gate must be re-run.
- **R35 parked the Cloud Run ID token.** That belongs to the Cup fork; the standalone build runs suppliers-sim as one local service.

**What this improves:**
- **Safety:** supplier free text never reaches a tool-holding context. Replies pass through the no-tools extractor into typed fields, and the run is tainted.
- **Precision:** prices in messages are rendered from rule values, never typed by a model.
- **Cost:** one bounded L1 call per round, with a deterministic default when the model is down or over budget.
- **Testability:** the deterministic default reproduces the I7/S1 answer key, and a planted out-of-set move falls back to it.
- **Portability:** plain `a2a-sdk` has no ADK-internal coupling.

**Decision (current).**
- **Server.** `suppliers-sim` hosts three A2A agents on the `a2a-sdk` server: one path each, one card each (the public URL, never `localhost`, gotcha 6), and personalities as data (`steady`, `discounter`, `premium`). Every one is labelled "Simulated supplier".
- **Client.** intel talks to them through a `SupplierPort` (`a2a-sdk` client) owned by the Inventory & Purchasing specialist (F8). Service auth is a shared secret in dev; the Cup fork uses an ID token (R37).
- **Rules.** `NegotiationPolicy` holds the hard limits: target and walk-away price, max rounds, allowed concessions. Each round it computes the allowed move set and a default move.
- **Moves.** An L1 call makes a typed choice from that set and writes short prose, which passes the number grammar. Out-of-set, error or budget → the default.
- **Outcome.** RFQs and counters are non-binding (R22). The deal review is deterministic code that emits the only output, a `purchasing.po.create.v1` **draft** with quote refs, for a named person to approve.

**Consequences:**
- The supplier screen, card and trace show "Simulated supplier" (CLAUDE.md rule 12).
- T-055a builds the rule half and T-055b the AI half (BOARD W3).
- A model outage degrades to the deterministic negotiator, never to an error state (rule 11).

# ADR-010 · Gemini model roles on the global endpoint

**Status:** accepted (9 Oct 2026) · **Ledger:** R4 K1, K7

**Context.** 2.5 models retire 20 Oct 2026; 3.x Flash has no India residency; global is cheaper.

**Decision.** Roles: `router` and `extract` → `gemini-3.5-flash-lite`; `reason` → `gemini-3.8-flash`; `narrate` → `gemini-3.5-flash-lite`; `vision` → `gemini-3.8-flash`; `embed` → Gemini embedding model; `live` → `gemini-3.8-live` (regional). IDs live in `platform.model_role` and are confirmed by a live probe before pinning. Data at rest stays in `asia-south1`.

**Consequences.** UNVERIFIED until the probe runs (no credentials on 9 Oct).

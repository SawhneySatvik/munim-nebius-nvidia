# ADR-001 · Modular monolith with one hard service boundary

**Status:** accepted (9 Oct 2026) · **Ledger:** R1, R10

**Context.** Two languages (TS core, Python ADK) and one trust boundary (intel proposes, core commits). One mostly-solo builder, nine days. R1: Segment/Fowler/Shopify evidence against early microservices (`FACT`).

**Decision.** core-api is a modular monolith; core-worker is the same image. The only hard boundary is core-api ↔ intel (plus suppliers-sim, which is a simulated external party). Module boundaries are enforced by dependency-cruiser in CI.

**Consequences.** Modules never join across each other's tables; they call each other's `index.ts` or react to events. Splitting a module out needs a measured signal (scaling profile, isolation need, deploy contention).

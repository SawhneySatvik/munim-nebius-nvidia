# ADR-006 · Graph is a per-tenant projection; Spanner Graph for the Cup

**Status:** accepted (9 Oct 2026) · **Ledger:** R6

**Context.** Multi-hop questions (supplier → ingredient → dish → outlet) benefit from a graph; Postgres stays canonical.

**Decision.** One Graph port, two adapters (FalkorDB pinned 4.x for dev; Spanner Graph, GoogleSQL dialect, one graph with `tenant_id` in keys, for the Cup). intel's projector rebuilds from events; nightly checksum detects drift. Spanner free-trial instance in a dedicated project (R4 K4).

**Consequences.** Graph down → SQL + search fallback. Contract suite runs against the Spanner emulator and FalkorDB in CI. Paid fallback ≈ $126/month.

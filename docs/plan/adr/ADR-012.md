# ADR-012 · Dev adapters excluded from the Cup repo

**Status:** accepted (9 Oct 2026) · **Ledger:** R9, R13

**Context.** Supabase is the dev environment; nothing submitted may contain Supabase/Vercel/AWS.

**Decision.** Dev adapters live only under `adapters/dev/`; `make export-cup` produces a fresh-history copy without them and fails if any file outside that path imports `@supabase` or `supabase`.

**Consequences.** The founder creates the public repo from the export. The export gate is red-proven by planting a forbidden import.

# ADR-002 · Postgres is the book of record, with forced RLS and tenant-led keys

**Status:** accepted (9 Oct 2026) · **Ledger:** R2, R9, R13

**Context.** Money and stock need transactions, constraints and append-only ledgers. Multi-tenant from day one. Supabase in dev, Cloud SQL in the Cup.

**Decision.** One Postgres. `tenant_id` leads every PK/FK/index. App role `munim_core` is non-owner with `FORCE ROW LEVEL SECURITY`. Context via `SET LOCAL app.*` per transaction; policies use `(select current_setting(...))`. No `auth.uid()`, `pgmq`, `pg_net`.

**Consequences.** Migrations must apply on vanilla Postgres 16 + pgvector (W1 gate, red-proven with a Supabase-only construct). Two-tenant canary isolation suite is a release blocker.

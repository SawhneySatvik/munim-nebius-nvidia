# ADR-003 · intel has no database write grant

**Status:** accepted (9 Oct 2026) · **Ledger:** R8, R15, R25

**Context.** intel runs models over untrusted text. The One Guarantee forbids anything changing the books without approval and requires every number to trace to a ledger row.

**Decision.** intel connects as `munim_intel_ro` (SELECT on `intel_ro` views only). Every intel write — claims, entities, edges, embeddings, wiki, forecasts, traces, findings, drafts, answers — goes through `/internal/intel/v1`, which validates and writes. Snapshots are minted by core-api from allow-listed templates.

**Consequences.** More endpoints; batch endpoints for traces and claims. W1 gate: a write with intel's credentials fails (red-proven).

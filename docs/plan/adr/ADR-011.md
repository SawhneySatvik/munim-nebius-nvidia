# ADR-011 · Config-driven country packs and a platform schema

**Status:** accepted (9 Oct 2026) · **Ledger:** R21, R24

**Context.** One setting must switch a merchant to another country; no country logic in code.

**Decision.** `platform.country_pack` holds versioned, schema-validated pack documents (currency, tax rules, invoice rules, formats, tz, aggregator import formats, compliance templates, chart of accounts, payroll scope, surcharge rules). Code reads the pack through `packages/core-domain/country`. Ships IN and AU. Operator changes are drafts. A business's country is immutable after its first posted ledger entry.

**Consequences.** Adding a country is data plus tests, not code.

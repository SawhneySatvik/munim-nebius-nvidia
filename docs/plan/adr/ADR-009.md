# ADR-009 · Identity Platform with Postgres memberships

**Status:** accepted (9 Oct 2026) · **Ledger:** R4 K11, R13

**Context.** Per-outlet roles; Identity Platform tenants and custom claims don't fit (1000-byte cap, stale until refresh).

**Decision.** One user pool. `core.membership` holds role and outlet scope; core-api resolves it per request and sets `SET LOCAL`. Operators listed in `platform.operator`. Seeded demo accounts for judges.

**Consequences.** Role changes take effect on the next request, not the next token refresh.

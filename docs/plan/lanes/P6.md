judges said they read a "Limitations" section as rigour, want to see which model does what, and want the aha fast.

## Rules

- Export from a commit only. Don't commit anything yourself; the orchestrator commits your files. The export must be
  re-runnable later from a newer commit (lane A2 is changing `services/intel` now; its work lands later).
- Never read `.env`; the export can never include it (commit-only + secret gates).
- No AI attribution in any exported or written file or commit (the export's single commit uses the identity and message
  from your rules; take the author from `git log -1 --format='%an <%ae>'` of this repo, not a tool name).

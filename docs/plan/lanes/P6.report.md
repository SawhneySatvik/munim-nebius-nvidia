- **Graph backend:** Postgres stays the default, so a judge needs no graph server.
  - FalkorDB ships as the optional `adapters/falkordb` (`MUNIM_GRAPH=falkordb`).
  - None of the FalkorDB export's FalkorDB-only exclusions or rewrites is copied.
- **Text map:** the FalkorDB export's `CLAUDE.md` rewording, unchanged.

    Kosambari's build must not carry `fraunces` (Cobnut's display face), where it previously had only the Shack's words.
    `--check` ran it: 0 hits each, both PASS.

  - `scripts/dev/restart-svc.sh`: one comment, `make up LOCAL_DB=1` → `make up`.
